# Installation

## 1. Install Tampermonkey extension
- For Chrome, install from the [Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en)
- For Edge, install from [Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) or the [Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en)
- For Firefox, install from [Firefox Add-Ons](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
- For Safari, install from the [Apple App Store](https://apps.apple.com/app/tampermonkey/id6738342400) for $2.99
